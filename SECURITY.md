# Security

## Reporting a vulnerability

Please report a vulnerability **privately**, through GitHub's private vulnerability reporting on this repository:
open the **Security** tab and choose **Report a vulnerability**. Do not open a public issue, pull request or
discussion about it.

Say what is affected, how to reproduce it, and what an attacker could do with it. You will get an answer in that
private advisory, and we will agree on the fix and the disclosure there.

## Supported versions

openbilling-rs has no release yet. Fixes go to `main`.
